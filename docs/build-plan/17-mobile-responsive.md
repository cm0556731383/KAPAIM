# שלב 17: רספונסיביות מובייל

**מה נבנה בפועל:**
- Tailwind responsive breakpoints על מסכי הבדיקה/מעקב העיקריים בלבד: לידים, משימות, כרטיס לקוחה, גבייה, סטטוס משלוחים (3.11, FR-8.20) — לא נדרשת חוויית עבודה מלאה בנייד, רק צפייה/בדיקה מהירה.

**תלויות:** אחרי ששלבים 4, 5, 8, 10, 15 קיימים (אלה המסכים הרלוונטיים למובייל).

**הגדרת סיום:** המסכים הנ"ל שמישים בדפדפן נייד (קריאים, לחיצים, לא שבורים).
