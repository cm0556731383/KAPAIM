# שלב 11: ספקים, הוצאות ותזרים

**ישויות:** `SUPPLIER`, `EXPENSE`.

**מה נבנה בפועל:**
- CRUD ספקים (שם, מס' חברה, סיווג עוסק, טלפון, מייל, הערות) + הצטרפות אוטומטית לרשימת "ספקים" (FR-5.26/FR-6.14–15).
- הזנת הוצאה ידנית: תאריך, סכום, ספק, תוכנית, הערות, העלאת חשבונית לקובץ ההוצאה (FR-6.5, FR-6.6) — קובץ החשבונית מקושר דרך `EXPENSE.document_id` ל-`DOCUMENT` הכללי שנבנה בשלב 7 (לא שדה קובץ נפרד), כדי לנצל את אותו מודל תבנית/עוסק פטור.
- זיהוי הוצאות חסרות חשבונית בסוף חודש (Job מתוזמן דרך Laravel Scheduler, באותו דפוס כמו תזכורות הגבייה בשלב 8) + שליחת תזכורת לספק דרך Smove (FR-6.7–FR-6.9, US-017) — קריאת ה-Smove בפועל תלויה בשלב 12.
- דוח הכנסות/רווח: הכנסה מחושבת מ-`PAYMENT`, הצגה לפי חודש/תוכנית; מנוי ששולם מראש נפרש על פני חודשי המנוי (FR-6.1–FR-6.4); רווח = הכנסה פחות הוצאה מיוחסת לתוכנית (FR-6.11–FR-6.13).

**כללים עסקיים מרכזיים:** US-016, US-017, FR-6.1–FR-6.15.

**תלויות:** שלבים 7 (מודל `DOCUMENT` לחשבונית הוצאה), 8 (תשלומים כבסיס להכנסה).

**הגדרת סיום:** ניתן לנהל ספק והוצאה, לראות דוח הכנסה/רווח לפי חודש ותוכנית, ולזהות הוצאות חסרות חשבונית.
