# שלב 14: חיפוש גלובלי

**מה נבנה בפועל:**
- חיפוש חוצה-ישויות (`LEAD`, `CUSTOMER` דרך `SCHOOL`/`CONTACT`) לפי שם/טלפון/ביה"ס, עם תוצאה שמזהה אם זה ליד או לקוחה ומנווטת לכרטיס המתאים (US-018, FR-7.14, FR-7.15).

**תלויות:** שלבים 4, 5.

**הגדרת סיום:** חיפוש טקסט חופשי מחזיר תוצאות רלוונטיות תוך פחות משנייה ומוביל ישירות לכרטיס.
