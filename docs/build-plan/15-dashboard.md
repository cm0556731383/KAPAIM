# שלב 15: מסך הבית / דשבורד

**מה נבנה בפועל:**
- מסך עבודה מרכזי (לא גרפים — שורות סיכום טקסטואליות, 1.3.11): לידים חדשים, ממתינות לשיחה חוזרת, Up Follow להיום, עסקאות ממתינות לתשלום/קבלה, סך פתוח לגבייה, צ'קים להפקדה, עסקאות ממתינות לשליחת חומרים, ביה"ס שלקח/התעניין בתוכנית האחרונה.
- כל פריט מוביל ישירות לרשומה הרלוונטית (FR-2.16, US-019); פריט שהושלם נעלם מהרשימה.
- זהו למעשה "שאילתות אגרגציה" מעל כל המודולים שנבנו בשלבים 4–11 — לכן הכי הגיוני לבנות אותו אחרון.

**תלויות:** שלבים 4, 6, 8, 9, 10 (הדשבורד שואב מכולם).

**הגדרת סיום:** מסך הבית מציג תמונת מצב חיה ומדויקת של כל הפריטים הפתוחים, עם ניווט ישיר מכל שורה.
