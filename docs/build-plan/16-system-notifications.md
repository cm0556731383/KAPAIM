# שלב 16: הודעות מערכת (UX Feedback Layer)

**מה נבנה בפועל:**
- ארבעה סוגי הודעה גלובליים: הצלחה / מידע / אזהרה (לפני פעולה בלתי הפיכה) / שגיאה עסקית (חוסמת + מסבירה) — FR-7.21–FR-7.26.
- זהו קומפוננטת UI רוחבית (Livewire flash/toast) שמוזרקת לכל השלבים הקודמים; אפשר וכדאי לבנות שלד שלה כבר בשלב 1, ולמלא תוכן תוך כדי כל שלב.

**תלויות:** משיק לכל השלבים; מוזכר כאן בנפרד כי הוא Cross-cutting ולא ישות DB.

**הגדרת סיום:** לכל פעולה חוסמת (gate עסקי) יש הודעת שגיאה עסקית ברורה; לכל פעולה בלתי הפיכה (מחיקה לוגית, ביטול מנוי) יש אזהרת אישור.
