# שלב 18: הגירת נתונים היסטוריים

**מה נבנה בפועל:**
- סקריפט/כלי ייבוא מ-Excel קיים ללידים/לקוחות/עסקאות היסטוריים (FR-8.21) — ממופה לישויות `SCHOOL`/`LEAD`/`CUSTOMER`/`DEAL` וכו', כולל יצירת רשומות `ACTIVITY_LOG` היסטוריות במידת האפשר כדי לשמר הקשר.
- ריצה חד-פעמית (או מספר ריצות עד לניקוי מלא של המקור), עם דוח שגיאות/חוסרים.

**תלויות:** כל שלבי הליבה (4–11) חייבים להיות בנויים לפני שיש לאן לייבא.

**הגדרת סיום:** הנתונים ההיסטוריים קיימים במערכת ונגישים דרך אותם מסכים כמו נתונים חדשים, בלי לאבד קשרים (ליד→לקוחה→עסקאות).
